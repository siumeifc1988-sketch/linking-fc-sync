1. 去 Firebase Console -> Project Settings -> General -> Your apps
2. 複製 firebaseConfig (apiKey, authDomain...)
3. 貼到呢個檔最頂 const firebaseConfig 度
4. Firestore Rules 要 Allow read: allow read: if true;
5. 上傳呢個 index.html 到 GitHub Pages，網站就會直接讀你貼嗰個 matches/76224918210018 嗰堆 collection
